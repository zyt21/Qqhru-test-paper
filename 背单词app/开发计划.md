> 交付目标：`release/背单词.html` 单个自包含文件，双击可用，通过 AC-01 ~ AC-22 全部验收标准。
> 执行方式：按 P0 → P8 九个阶段顺序开发；**每个阶段结束都必须是一个可运行、可演示的版本**，并完成该阶段对应的验收项。

## 1. 总体技术决策（先定死，开发中不再摇摆）

| # | 决策点 | 决定 | 理由 |
|---|---|---|---|
| 1 | 技术栈 | 纯原生 HTML / CSS / JavaScript，不用框架、不用 npm 依赖、无构建步骤 | 交付物是双击即用的单文件，file:// 下必须零外部依赖 |
| 2 | 脚本加载 | 使用经典 `<script src>`（非 ES Module） | ES Module 在 file:// 下受 CORS 限制无法加载 |
| 3 | 开发形态 | 开发期 `src/` 多文件组织；发布期用脚本内联为单文件 | 兼顾可维护性与单文件交付 |
| 4 | 数据存储 | IndexedDB 主存 + localStorage 降级（同 API 封装），schema 带版本号与迁移函数 | PRD 第 7 节；降级时显著提示容量风险 |
| 5 | 第三方库 | 仅 2 个，均为打包期内联、运行时离线：SheetJS（Excel 解析）、jsPDF（PDF 导出） | PRD 要求 Excel 导入与 PDF 导出；CSV 解析自写 |
| 6 | 时间处理 | 全部用本地时区 ISO 字符串；“学习日”以凌晨 4:00 为界（设置可改） | 深夜学习计入当天，避免跨天打卡争议 |
| 7 | 模块化 | 全局命名空间 `window.VW`，逻辑层与 UI 层分离；逻辑层为纯函数 | 便于 `?selftest` 自动化自检 |
| 8 | 自检机制 | 页面地址加 `?selftest` 进入内置自检页，一键跑逻辑断言 | 纯静态环境没有测试框架，浏览器内自检最可行 |
| 9 | 界面语言 | 全中文 UI | — |
| 10 | 词条主键 | `spelling` 归一化（小写、去首尾空格）后作为合并/去重键 | PRD 版本更新与导入合并按拼写进行 |

## 3. 开发规范（约束所有阶段的代码）

1. **分层**：`logic/` 内禁止访问 DOM / localStorage / IndexedDB；`ui/` 负责渲染与事件；`core/` 负责持久化。自检只测 `logic/`。
2. **命名**：模块挂 `VW.db / VW.store / VW.scheduler / VW.queue / VW.quiz / VW.import / VW.stats / VW.points / VW.backup / VW.export / VW.ui`。
3. **数据**：
   - 时间一律 ISO 字符串；到期比较用“学习日边界”（默认 04:00）截断为日期后比较；
   - 枚举：`mastery ∈ {new, learning, familiar, mastered, stubborn}`；`stage ∈ 0..6`；`result ∈ {know, fuzzy, unknown}`；
   - ID 生成：`crypto.randomUUID()`，不支持时用时间戳+随机数兜底。
4. **UI**：每个页面一个渲染函数 + 事件委托（不逐条绑监听）；所有列表分页/滚动加载，5000+ 词条不卡顿。
5. **提交节奏**：每个任务（T 编号）完成即手动验证；每个阶段结束跑一次 `?selftest` 并过该阶段 AC 项。

## 6. 依赖与并行关系

- **串行主链**：P0 → P1 → P2（P2 依赖 P1 的词条数据与 P0 的存储）→ P3（依赖 P2 的作答写回）→ P4 → P7。
- **可并行**：P5（测评）与 P6（统计）均依赖 P2 的 quiz 引擎与日志，可在 P3/P4 之后并行开发；P6 的日历组件与 P4 的打卡同时做。
- **不可提前**：P7 的首页装配必须最后（依赖所有模块的摘要接口）；P8 的打包与全量验收必须在全部功能完成后。
- **关键路径**：P2 核心学习是风险与工时双高点，建议排在最精力充沛的时间段；P0 的存储层一旦定型，后续所有模块都依赖它，务必一次做对。

## 7. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| file:// 下 IndexedDB 不可用（个别浏览器/隐私模式） | 数据丢失风险 | P0 即探测；同 API 降级 localStorage 并显著提示；备份提醒强制可见 |
| localStorage 容量（约 5MB） | 降级模式下大词库放不下 | 降级模式限制单次导入词条数并提示换浏览器 |
| Excel 解析失败（老 xls 格式、加密文件） | 导入失败 | 支持 .xlsx（SheetJS）；失败提示另存为 CSV；CSV 自写解析器零依赖 |
| 单文件体积过大（jsPDF+SheetJS 内联约 1.5MB） | 打开变慢 | 可接受；两者均为惰性加载（用到时才解析执行） |
| 大词库性能（5000+ 词条） | 卡顿 | 列表分页渲染、搜索内存索引、逻辑层 O(n) 预计算缓存 |
| 手机与电脑数据独立 | 用户困惑 | 使用说明 + 设置页常驻说明文字；备份文件名含日期 |
| 深夜跨天打卡争议 | 体验问题 | 学习日边界默认 04:00 且可设置 |
| schema 升级导致旧数据不兼容 | 数据损坏 | migrate.js 版本化迁移；升级前强制提示备份 |
