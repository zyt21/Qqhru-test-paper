> 适用范围：第一版（V1）本地单机网页应用。后续所有开发以本文档为准。

## 0. 已确认的关键决策

| 项目 | 决定 | 影响 |
|---|---|---|
| 词库来源 | 用户稍后提供固定词库；应用先做好导入与字段适配，并内置一个几十词的示例词书用于测试 | 必须先完成导入工具与结构化词条模型 |
| 发音功能 | **本期不做**（无真人音频、无 TTS） | 音标字段保留展示；听音类题型全部移除；“听写”改为看中文释义拼英文 |
| 使用设备 | 电脑浏览器为主，偶尔手机浏览器 | 必须做响应式布局 |
| 启动方式 | 双击单个 HTML 文件直接打开 | 所有代码/资源自包含；不依赖网络、不依赖服务器 |
| 数据存储 | 浏览器本地存储（IndexedDB 为主），无登录、无联网、无云端 | 刷新、关闭、重启后数据不丢；数据跟随浏览器 |
| 记忆算法 | 简化艾宾浩斯为主（固定间隔序列，可调参数） | SM-2 / FSRS 列入后续版本，本期不做 |
| 范围 | 单人自用，砍掉社交、多端同步、音频类功能（详见第 9 节） | — |

## 1. 产品目标与使用场景

### 1.1 产品目标

- 做一个**仅供自己使用**的本地背单词网页程序：双击一个 HTML 文件即可使用，无需安装、无需登录、无需联网。
- 以**结构化词条 + 简化艾宾浩斯复习调度 + 多题型验证**为核心，帮助用户按计划记住单词、消灭错词，并可视化地看到自己的进度与遗忘情况。
- 数据全部保存在浏览器本地，通过备份文件保证长期不丢。

### 1.2 使用场景

1. **日常学习**：每天打开页面 → 首页看到今日任务（新词 + 到期复习 + 逾期 + 顽固词）→ 一键开始背词 → 完成后打卡。
2. **计划管理**：选定词书、设置每日新词量和目标日期，系统自动倒推每日任务；多词书并行学习。
3. **错词消灭**：答错的词自动进入错词本，通过专项复习连对后自动移出；反复错的词进入顽固词队列强化。
4. **阶段检验**：单元学完做单元测、词书学完做结课测、随时做限时挑战，检验掌握度。
5. **查词与整理**：随时用全局词典搜索查词、手动加生词、编辑词条、批量整理词书。
6. **换设备/备份**：定期导出备份文件；换电脑或换浏览器时导入恢复；手机浏览器偶尔打开也能学习（数据独立，靠备份迁移）。

## 2. 整体页面框架与导航结构

### 2.1 运行形态

- 交付物：**单个自包含 HTML 文件**（CSS/JS 全部内联），双击即用，浏览器推荐 Chrome / Edge。
- 无需本地服务器、无外部资源引用、完全离线可用。

### 2.2 导航结构（8 个一级页面）

**桌面端（≥768px）**：左侧固定侧边栏导航，右侧内容区。

| # | 页面 | 导航名 | 职责 |
|---|---|---|---|
| 1 | 首页 | 首页 | 总览摘要 + 今日任务入口 + 各模块摘要 |
| 2 | 今日学习 | 学习 | 核心背词流程（新词 + 复习 + 各种学习模式） |
| 3 | 词书管理 | 词书 | 词书/词条的内容管理（增删改查、导入、版本） |
| 4 | 生词与错词 | 错词 | 错词本、生词本、易混词本、收藏、笔记 |
| 5 | 测评 | 测评 | 每日小测、单元测、结课测、限时挑战 |
| 6 | 统计报告 | 统计 | 学习记录、遗忘曲线、打卡日历、报告 |
| 7 | 词典搜索 | 词典 | 全局搜索词条、查看详情、快速编辑 |
| 8 | 设置 | 设置 | 学习计划参数、算法参数、外观、备份恢复、导出 |

**移动端（<768px）**：顶部标题栏 + 底部 5 个主 Tab（首页 / 学习 / 词书 / 错词 / 统计），右上角「更多」菜单进入 测评 / 词典 / 设置。页面内不使用横向滚动。

### 2.3 通用交互规范

- 全局支持**深色模式 / 护眼模式**（护眼 = 米黄底色低对比），切换后持久保存。
- 学习页支持键盘快捷键（见 5.1），其余页面保证鼠标/触摸可完成全部操作。
- 顶部/首页显示**提醒条**：今日未学习、有逾期词、距上次备份超过 7 天时出现。
- 所有破坏性操作（删除词书、清空数据、覆盖导入）必须有二次确认。

## 3. 首页内容结构

首页 = 「今日任务主卡 + 模块摘要卡 + 日历 + 快捷入口」，从上到下：

| 区块 | 内容 | 来源数据 |
|---|---|---|
| ① 问候栏 | 问候语、连续打卡天数、今日积分、当日日期 | 统计模块 |
| ② 今日任务主卡（最醒目） | 今日待学：新词 X · 到期复习 Y · 逾期 Z · 顽固词 W；一个大的「开始学习」按钮；今日已完成进度条（已学/总量） | 今日计划 |
| ③ 提醒条 | 逾期 N 天未清、备份超期、目标日期临近等提醒 | 全局 |
| ④ 快捷入口（宫格） | 词书管理、错词本、测评、词典搜索、统计报告、设置 | 静态导航 |
| ⑤ 学习模式入口 | 闯关模式、听写模式、错词专项、考前冲刺（一键进入对应模式） | 学习模块 |
| ⑥ 各模块摘要卡（一行多卡，可点进详情） | 词书：当前词书名 + 进度百分比；错词：错词数 + 待消灭数；测评：最近一次成绩；统计：本周新词/复习/正确率；计划：预计完成日期 | 各模块汇总 |
| ⑦ 学习日历 | 当月月历：打卡日打勾、补学日标记、未来日灰显；点过去日期可查看当日记录并补学 | 统计模块 |

首页是**只读总览 + 入口**，不在首页直接改数据；一切数字点按跳转到对应模块。

## 5. 各模块 V1 必需数据与操作

### 5.1 今日学习（核心模块）

**用途**：执行背词主流程，是每日使用的主入口。

**必需数据**（输入与输出）：
- 输入：启用中的词书、设置中的计划参数（每日新词量/复习上限）、每个词条的记忆状态（下次到期时间、阶段、错误次数等）。
- 输出：今日队列、本轮学习结果，写入记忆状态、错词本、打卡与统计记录。

**队列生成规则（优先级从高到低）**：顽固词 → 逾期词 → 今日到期 → 新词（直到达到每日新词量）。

**学习模式（6 种，同一套引擎不同取词规则）**：
1. 新词学习：学当日新词，先展示完整词条卡（拼写、音标、词性、释义、例句、搭配等），再进入题型验证；
2. 到期复习：取今日到期 + 逾期 + 顽固词；
3. 闯关模式：按词书单元分组，连续答对闯关，可反复挑战；
4. 听写模式（无音频版）：看中文释义拼英文，全拼写题；
5. 错词专项：取错词本队列；
6. 考前冲刺：目标词书内高密度限时循环，答错重点标记。

**题型（6 种）与判定**：
| 题型 | 形式 | 判定 |
|---|---|---|
| 认词·英→中 | 显示英文，4 个中文选项 | 选对=认识，选错=不认识 |
| 认词·中→英 | 显示中文，4 个英文选项（含形近干扰） | 同上 |
| 拼写填空 | 看释义+例句填空，可选首字母提示或乱序字母拼块 | 拼对=认识 |
| 例句填空 | 例句挖空 + 选项/输入 | 选对=认识 |
| 选择辨析 | 近义/形近词干扰选择 | 选对=认识 |
| 卡片翻转 | 正面拼写+音标，翻面看释义；左右滑（右=认识、左=不认识）或按钮 | 滑动即反馈 |

**防“假认识”规则**：到期复习中，认词/选择/卡片题答“认识”只算初步通过，必须再经一道**拼写类题（拼写填空/中→英输入）验证通过**才允许升级间隔；拼写失败按“模糊”处理。

**操作清单**：
- 选择词书范围 / 模式 → 生成队列 → 开始；
- 逐词作答（点击选项、输入拼写、滑卡片）；即时对错反馈 + 解析（义项/辨析说明）；
- 快捷键：`→`/`空格`=认识，`←`=不认识，`1-4`=选选项，`F`=翻卡；
- 结束结算页：本轮词数、对/错/模糊统计、连对奖励积分、错词列表、可「再学一遍错词」；
- 中途退出自动保存进度（下次从队列继续）。

### 5.2 词书管理

**用途**：词库内容层与后台管理。

**必需数据**：
- 词书：名称、类型（考试/教材/自定义）、简介、标签、版本号、更新日志、词数、启用状态、创建/更新时间。
- 词条：结构化字段见附录 A（拼写、英/美音标、词性、多义项、例句+翻译、搭配、同/反义词、词根词缀、图片/助记/词源[可选]、考试标签、难度、词频、所属词书+单元/List、自定义标签、笔记、收藏）。

**必需操作**：
- 创建 / 删除 / 重命名 / 启用停用词书；
- 词条增删改查（表单支持全部字段）；批量编辑（多选后改标签/单元/难度等）；
- **导入**：Excel/CSV（提供列名模板与自动列映射）、JSON（结构化直导）、粘贴文本（一行一词，先只建拼写再补字段）；
- **版本更新**：为词书更新版本号，导入新版本时按“拼写”合并：内容字段覆盖为新版，**保留用户学习状态、笔记、收藏、标签**；
- 词书内按单元/List 分组浏览，显示每词学习状态与掌握度；
- 导出词表（Anki txt / PDF，见 7.5）。

### 5.3 生词与错词

**用途**：错误与生词的集中管理与专项强化。

**必需数据**：错词本（错误次数、连续答对次数、最近错误时间）、生词本（手动/自动加入）、易混词分组（形近/近义/同根三类，可手动成组）、收藏标记、笔记。

**必需操作**：
- 答错自动入错词本（同词多书不重复计入）；
- **消灭错词**：在错词本中连续答对 N 次（默认 2，可设置）自动移出；
- 手动移入/移出生词本、收藏/取消收藏、写笔记；
- 易混词组：查看推荐分组（形近/近义/同根），手动增删成员；
- 错词专项复习、错词测试（从错词本组卷）；
- 顽固词区：累计错误 ≥ 阈值（默认 3）的词集中展示，每日必出。

### 5.4 测评

**用途**：阶段性检验掌握度。

**必需数据**：测试记录（日期、类型、范围、题数、得分、用时、错词快照）。

**必需操作**：
- 每日小测（从最近 7 天学过的词 + 错词抽 10 题）、单元测（该单元已学词抽样）、结课测（词书全部已学词抽样）、限时挑战（60 秒连续作答，答对 +1 分，答错扣时或结束）；
- 组卷题型比例：认词 40% + 拼写 30% + 辨析 30%；
- 交卷判分，展示错词解析；错词自动入错词本；成绩写入统计。

### 5.5 统计报告

**用途**：学习记录、遗忘分析与打卡管理。

**必需数据**：每日学习记录（新词数、复习数、正确率、积分）、打卡记录（日期、连续天数）、补签卡余额、遗忘曲线采样点（各间隔档的按期复习率/正确率）、词书进度、预计完成日期。

**必需操作**：
- 查看今日/近 7 天/累计报告；
- 打卡日历：点击过去未学日可用补签卡补签（连续天数规则同步计算）；
- 遗忘曲线图（折线）；按词书/时间范围筛选；
- 预计完成日期 = 剩余未学词数 ÷ 每日新词量（随设置与目标日期动态显示）。

### 5.6 词典搜索

**用途**：全局查词与快速维护。

**必需数据**：全词条索引（拼写 + 中文释义）。

**必需操作**：
- 搜索：英文前缀/子串、中文关键词模糊匹配；输入即时出结果；
- 词条详情：展示全部字段 + 该词学习状态；可编辑字段、加入生词本/收藏、写笔记；编辑结果全局同步。

### 5.7 设置

**用途**：计划参数、算法参数、外观与数据安全。

**必需数据/操作**：
- 学习计划：每日新词量（默认 20）、每日复习上限（默认 100）、目标日期（自动倒推每日任务）、补学开关；
- 算法参数：间隔序列（默认见附录 B）、顽固词阈值（默认 3）、错词移出连对次数（默认 2）、拼写验证开关（默认开）；
- 外观：深色 / 护眼 / 跟随系统；
- 数据：一键备份、恢复导入、清空数据、导出 Anki/PDF（见第 7 节）；
- 页面内提醒开关（页面打开时的任务提醒条）。

## 6. 首页、今日计划与各模块之间的关系

### 6.1 数据流（单向闭环）

```
            ┌────────────────────────────────────────────────┐
            │                   词书管理（内容层）              │
            │  词书 / 词条 / 单元 / 标签 / 版本                 │
            └───────────────┬────────────────────────────────┘
                            │ 提供词条内容
                            ▼
   设置（参数：每日新词量/复习上限/间隔序列）  ──►  今日计划（队列生成）
                                                      │
                          记忆状态（阶段/到期时间/错误次数）│
                                                      ▼
                                                今日学习（作答）
                                                      │ 写入
                              ┌───────────┬───────────┼───────────┐
                              ▼           ▼           ▼           ▼
                          记忆状态更新   错词/生词本   打卡+统计记录   测评数据(错词回收)
                              │           │           │           │
                              └───────────┴───────────┴───────────┘
                                          ▼
                       首页（聚合所有摘要，触发下一次今日计划）
```

### 6.2 关系说明

1. **首页不产生数据**：只读取“今日计划 + 各模块摘要”做展示，是总览与入口。
2. **今日计划是调度中枢**：由「词书内容 + 设置参数 + 记忆状态 + 打卡历史」四者计算得出每日队列；它本身不存内容，只产出任务清单。
3. **今日学习是唯一写入学习结果的地方**：作答结果同时更新记忆状态、错词本、打卡与统计，形成闭环。
4. **错词与测评相互回收**：学习答错 → 错词本；测评错词 → 错词本；错词本 → 专项复习/测试 → 连对移出。
5. **词书管理与词典搜索共享同一词条数据**：任一处编辑全局生效；学习状态独立挂在词条上，多词书并行时按词书内词条进度分别统计，同一词条只维护一份记忆状态（同词不重复学）。

## 7. 本地数据、备份与恢复

### 7.1 存储技术

- 主存储：浏览器 **IndexedDB**（承载词库、学习状态、统计等全部数据）。
- 辅助存储：**localStorage**（界面偏好、上次备份时间等小配置）。
- 降级方案：若浏览器不支持 IndexedDB，自动降级为 localStorage 全量 JSON，并显著提示容量风险与备份要求。
- **限制（用户已知晓）**：数据跟随浏览器；换浏览器/清空浏览器数据会丢；手机与电脑是两份独立数据，靠备份迁移。

### 7.2 数据模型总览（实体清单）

| 实体 | 说明 |
|---|---|
| book | 词书（含版本号、更新日志） |
| entry | 词条（结构化内容，见附录 A） |
| learningState | 每词条的复习状态（首次学习时间、上次复习、下次到期、阶段、连对数、错误数、掌握度） |
| reviewLog | 每次作答流水（词、题型、结果、时间） |
| dailyRecord | 每日聚合（新词数、复习数、正确率、积分、打卡） |
| wrongList / rawList / favorite / notes | 错词/生词/收藏/笔记标记 |
| confuseGroup | 易混词组（形近/近义/同根） |
| testRecord | 测评记录 |
| settings | 全部设置参数 |

### 7.3 备份与恢复

- **备份**：一键导出 `backup-YYYYMMDD.json`（含：应用版本、导出时间、settings、books、entries、learningState、reviewLog、dailyRecord、全部标记与标签）。文件由浏览器下载保存。
- **恢复**：选择备份文件导入，提供「覆盖恢复」（清空后重建）与「合并恢复」（按词条拼写/ID 合并，保留两边更优状态）两种方式，均有二次确认。
- **自动提醒**：打开页面时，若距上次备份超过 7 天，首页显示备份提醒条。
- **迁移**：换电脑/换浏览器 = 导出备份 → 新环境导入；手机偶尔学习后，可用同一方式把记录迁回电脑（提示用户手机上仅用于临时学习时不必回迁）。

### 7.4 其他导出

- **Anki**：导出词表/错词本为 `.txt`（拼写 + 释义，Anki 可直接导入格式）。
- **PDF**：内置轻量 PDF 生成（jsPDF 内联），导出词表/错词本为表格 PDF。

## 附录 B：简化艾宾浩斯默认参数（设置页可调）

| 档位 stage | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 下次复习间隔 | 当天 | 1 天 | 2 天 | 4 天 | 7 天 | 15 天 | 30 天 |

- 认识（且通过拼写验证）→ stage +1；模糊 → stage 不变、当日重排；不认识 → stage −1（最低 0）、errorCount +1。
- stage 达到 6 后维持 30 天循环，直至标记“掌握”。
- 顽固词：errorCount ≥ 3 → 进入顽固队列，每日必出，连对 2 次退出并回到原档位。
- 错词本移出：连续答对 2 次（可调）。

## 附录 C：题型与学习模式的对应关系

| 模式 | 使用题型 |
|---|---|
| 新词学习 | 词条卡展示 → 认词（英→中/中→英）→ 拼写填空 |
| 到期复习 | 6 种题型随机轮换，认词/选择/卡片题后必须拼写验证 |
| 闯关模式 | 认词 + 拼写 + 辨析，按单元连对通关 |
| 听写模式 | 仅中→英拼写（看中文释义拼英文，无音频） |
| 错词专项 | 同到期复习，取词范围为错词本 |
| 考前冲刺 | 限时循环认词 + 拼写，答错高亮标记 |
